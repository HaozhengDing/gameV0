# gameV0

一款中式克苏鲁 Roguelite：你进入一个个「有规矩」的空间，观察并试错规则，用符箓与五行元素组合破局；探索越深，认知污染越重，也越接近真相。

- 类型：国风克苏鲁 × Noita 式元素沙盒 × Roguelite
- 引擎：Godot 4.x（倾向，待最终确认）
- 平台：PC / Steam 优先
- 状态：设计阶段（MVP 范围见 docs/00-brief.md）

## 文档

- [docs/00-brief.md](docs/00-brief.md) — 项目 brief / 设计提示词
- 后续：core-loop、mechanics、fate-cards、narrative、tech

## 设计原则（红线）

- 机制优先，范围优先：一个核心 twist 做深，其余做薄
- 随机必须有选择：命格三选一，代价可发现、可推理
- 每个命格都能通关（方向差异 > 强度差异）
- 买断制，不做抽卡 / 内购
- 取《道诡异仙》的气质，不改编、不抄设定

# 刍狗（工作标题）· gameV0

> 天地不仁，以万物为刍狗。

你是天师府今年派下山的方士。渎县一夜之间消失，矿监挖穿的矿井直通归墟；在你之前下山的人，都成了祠堂里的牌位。

你用符箓「编程」：符头、符胆、符脚拼成一句法术，打在会燃烧、流动、反应的民俗物质上。硝、硫、炭遇火即爆，糯米能净阴气，水银是「它们」越不过的线。你一层层往下挖，直到发现手里的符，本就是「它们」的文字。

- 类型：符箓编程 × 民俗物质沙盒 × 高难度 Roguelite（国风克苏鲁）
- 引擎：倾向 Godot 4.x，模拟核心写成独立的纯逻辑模块；随 M0 实验 A 最终确认
- 平台：PC / Steam 优先
- 开发：个人制作人 + AI 实现
- 状态：设计收敛完成；下一步做 M0 三项实验（2026-11-15 起 8 周，2027-01-10 评审）

## 做什么、不做什么

依据 [docs/01-decision-twist.md](docs/01-decision-twist.md)：

| 深做 | 做薄 | M2 之后 / EA 之后 |
|---|---|---|
| **可读的元素沙盒**：符箓三段式 × 民俗物质反应 | **神智**：符箓的代价轴<br>**规矩**：关卡的叙事规则层 | 阴面、纸扎、鬼市、祠堂怨灵、入魔深层内容、双货币（M2 后）<br>命格三选一（EA 后） |

MVP（M1）= 矿井 1 层 + 洞天 + 符箓三段式 + 七星灯 + 神智与可逆入魔。

地层：山门 → **矿井** → 地宫 → 龙脉 → 水府 → 幽都 → 归墟 → 混沌。MVP 只做矿井。

## 设计原则（红线）

- **一个核心做深**：符箓 × 物质，其余做薄。
- **可读优先**：反应前后一致、看得见；污染只遮蔽未知，不遮蔽已知。
- **代价只为"知道得太多"付**：神智只从目睹、禁书、阴面、禁符四处流失；普通施法不收神智税。
- **规矩由世界兑现**：违反规矩，发生的是一次反应或一个实体，而不是扣一笔数值。
- **随机必须有选择**：MVP 里由洞天传法三选一承担；命格三选一在 EA 回归，每个命格都能通关（方向差异 > 强度差异）。
- **疯了还能回来**：入魔是可进出的状态（参考饥荒），心魔会变实，也会掉东西；每次入魔留一道魔痕。
- **死亡只带走知识**，不带走数值。
- **买断制**，不做抽卡 / 内购。
- 取《道诡异仙》的气质，不改编、不抄设定；原典（《山海经》《道藏》《天工开物》）可考，克苏鲁映射只作内部脚手架，不写进对外叙事。

# 国风克苏鲁作品特征卡 v0.2（已筛选）

> 收录标准：有「不可名状 / 认知规则 / 神性与代价」内核，且能拆出命名法或世界架构。纯民俗恐怖不入主库（末尾有排除清单与理由）。
> 每条的「可偷」= 命名法 / 世界架构 / 角色功能 中最值得拿的部分。

## 一、核心收录（13）

1. **《道诡异仙》** — 狐尾的笔 / 网文
   - 一句话：大学生在精神病院与诡异修仙世界之间穿梭，分不清哪边真实。
   - 独特性：把「不可靠叙述」做成主角的日常体验；修仙本身就是吃人的骗局。
   - 世界架构：双世界（现代都市 / 诡异修仙）+ 司命-天道神系 + 修行即污染。
   - 命名：李火旺（土气本名）、丹阳子（道号）、坐忘道（道家术语反用成骗徒组织）、白玉京（神话地名）、心素（概念造词）、司命（神职）。
   - 恐怖内核：认知不可靠 + 成仙骗局 + 身边人接连死亡。
   - 可偷：双世界切换、心素式污染、假导师/骗局组织、本名+道号双层命名。克苏鲁浓度 5/5。

2. **《诡秘地海》** — 狐尾的笔 / 网文
   - 一句话：穿越成地底海洋的船长，驾蒸汽船寻找「地表」，人逐渐偏执。
   - 独特性：把海洋克苏鲁搬进「地底海 + 蒸汽船」，用航海单元剧堆疯狂。
   - 世界架构：末日后的地下收容所世界；「地表」是传说与麦高芬。
   - 命名：查尔斯（西名）、地海、地表（地理命名）；船员职位/船名可做体系。
   - 恐怖内核：探索越深，人越偏执；忠诚与疯狂的拉扯。
   - 可偷：航海式单元关卡、船员关系/资源、麦高芬式目标。浓度 4/5。

3. **《巴虺的牧群》** — oobmab / 短篇
   - 一句话：考古学家发疯失踪，后人循线深入四川，发现远古文明与「巴虺」。
   - 独特性：中国考古/地方史考据体克苏鲁；真相是「牧群」关系。
   - 世界架构：现实中国 + 远古文明遗迹 + 神祇-牧群。
   - 命名：巴虺（古国名+毒蛇字）、牧群（神对人的称呼）、考古报告体。
   - 恐怖内核：考据即污染，知道得越多越不能回头。
   - 可偷：文献/考据叙事、地域神话、真相碎片收集。浓度 5/5。

4. **《黑太岁》** — oobmab / 短篇
   - 一句话：退休教授痴迷家族秘辛，挖出绵延千年的「长生之毒」。
   - 独特性：家族史 + 民俗物「太岁」变成 cosmic 载体。
   - 世界架构：现代中国 + 家族秘史 + 长生/异变体系。
   - 命名：黑太岁（颜色+民俗物）、劳铭昌（普通姓名）、太岁（民俗词异化）。
   - 恐怖内核：长生 = 异变；家族业障由后代承担。
   - 可偷：家族线、身体异变资源、民俗物 = 危险物。浓度 5/5。

5. **《深海余烬》** — 远瞳 / 网文
   - 一句话：雾海时代，幽灵船与亡者城邦并存，旧日阴影沉在海底。
   - 独特性：后启示录航海 + 诡异气象；世界已死但还在运转。
   - 世界架构：雾海 / 亡者城邦 / 旧日阴影三层空间。
   - 命名：雾海、亡者城邦、旧日阴影（用气象与地理命名恐怖）。
   - 恐怖内核：秩序消失后的「日常化诡异」；希望与绝望循环。
   - 可偷：异象地理、船/城邦关卡、环境叙事。浓度 4/5。

6. **《动物园规则怪谈》** — phKeaLx（十六椰子）/ 规则怪谈
   - 一句话：游客指南、员工手册、水族馆通知互相矛盾，你得判断哪条能信。
   - 独特性：纯规则文本构成恐怖；多视角+信息差；实体始终无名（「它」）。
   - 世界架构：规则空间——同一座动物园，游客/员工/水族馆各有一套规则层。
   - 命名：游客指南、员工手册、水族馆通知、它（机构文本 + 无名化）。
   - 恐怖内核：规则不明但可推理；违反即死。
   - 可偷：规则即引导/玩法、文本即关卡、无名实体。规矩系统 5/5。

7. **《还愿》** — 赤烛游戏 / 游戏
   - 一句话：1980 年代剧作家为治女儿怪病求助私坛，全家被「慈孤观音」吞噬。
   - 独特性：私坛邪神 + 家庭伦理；玩家扮演的是「加害者父亲」。
   - 世界架构：1980s 台湾 + 慈孤坛/慈孤观音私佛体系 + ARG 延伸。
   - 命名：慈孤观音（慈+孤+观音）、慈孤坛、何老师、陆心青年会、杜丰于/杜美心。
   - 恐怖内核：迷信交易把人一步步吞噬；面子与父职。
   - 可偷：私坛规则、「还愿」交易、普通人堕落事件链。浓度 4/5。

8. **《暖雪》** — 烂泥游戏 / 游戏
   - 一句话：天降「暖雪」，刺客狴犴前往皇城，揭开王朝与慈母教/何罗神的旧事。
   - 独特性：把克苏鲁神话「本土化」成国风王朝 + 教派 + 异象。
   - 世界架构：龙武王朝 + 暖雪异象 + 慈母教/何罗神信仰。
   - 命名：暖雪（反常识气象）、龙武帝、慈母教、何罗神、狴犴（神兽名）、四大家族。
   - 恐怖内核：王朝衰败 + 邪神信仰；身体异变。
   - 可偷：异象世界观、教派组织、BOSS 命名法。浓度 4/5。

9. **《无量疯之章》** — 五条虾仁工作室 / 游戏
   - 一句话：90 年代，脑部受伤的风水先生一边吃药抗幻觉，一边清除污染。
   - 独特性：90 年代气功热/精神病院氛围 + 视觉小说；「治疗」与「污染」同源。
   - 世界架构：90 年代中国 + 幻觉/梦境层 + 污染值。
   - 命名：无量疯之章（佛道量词 + 疯 + 章回体）、风水先生（职业称谓）。
   - 恐怖内核：精神异象；分不清是在治病还是在加深污染。
   - 可偷：精神异象 UI、年代美术、污染系统、低成本 VN。浓度 5/5。

10. **《双瞳》** — 陈国富 / 电影
    - 一句话：台北命案死者体内都有同一种霉菌，线索指向道观与双胞胎的「成仙」。
    - 独特性：道教成仙 + 现代刑侦；真菌/钢珠的身体恐怖；双胞胎共生。
    - 世界架构：现代台北 + 真仙观/交阯道派 + 成仙渡劫。
    - 命名：黄火土（姓名含五行）、谢亚理、真仙观、交阯、成仙/渡劫（道教术语）。
    - 恐怖内核：成仙的代价是别人的命；理性调查 vs 玄学。
    - 可偷：仪式型 BOSS、双胞胎/共生、现代+玄学双线。浓度 4/5。

11. **《咒》** — 柯孟融 / 电影
    - 一句话：禁忌影像的诅咒落到女儿身上，母亲试图用民俗仪式化解，却走向献祭。
    - 独特性：伪纪录片 + 诅咒传播 + 打破第四面墙；观众成为共犯。
    - 世界架构：现代台湾 + 陈家庄/大黑佛母信仰 + 影像传播规则。
    - 命名：大黑佛母（色+佛母）、陈家庄、陈氏、手印/咒语。
    - 恐怖内核：母爱与献祭的错位；传播即诅咒。
    - 可偷：诅咒传播机制、第四墙、民俗仪式流程。浓度 4/5。

12. **《传武》** — GK 工作室 × Blacksad 黑猫 / 漫画
    - 一句话：大晋修行界对抗域外邪神；克苏鲁神话被翻译进中国修行体系。
    - 独特性：邪神「本土化」——克苏鲁、克图格亚、拉莱耶、深潜者都有中国化身份。
    - 世界架构：大晋王朝 + 三十六洞天 + 域外邪神/失序世界。
    - 命名：十善（法号）、大晋、山阴、红尘仙、阴司君王、三十六洞天、克图格亚/拉莱耶/深潜者（音译+本土化）。
    - 恐怖内核：修行与邪神同源；力量来自不可名状。
    - 可偷：体系命名法（境界/组织/邪神翻译）、势力设计。浓度 4/5。

13. **SCP-CN / 中华异学会** — SCP 中文分部 / 群体
    - 一句话：用「收容规则 + 档案」写出的国风异常组织与条目。
    - 独特性：档案体 + 官僚式恐怖；把民俗和历史写成收容条款。
    - 世界架构：现代中国 + 异常收容体系 + GOI 组织网络。
    - 命名：编号 + 项目名；中华异学会；收容/项目/分级术语。
    - 恐怖内核：规则化的不可名状；「官方口径」本身就恐怖。
    - 可偷：档案体叙事、组织设定、规则文本。浓度 4/5。

## 三、排除清单（民俗/社会派恐怖，暂不入主库）

# 2D 战斗的打击感与命中辨认

- 更新于 2026-11-21
- 状态为待试验。已核对本作规格与代码，以下 A/B 尚待制作人实机验证。

**先用现版复现症状。** 如果施法者常分不清空放、普通命中和击杀，优先试一轮命中音色 A/B。如果火势、敌人或站位在画面上难追踪，先测减弱镜头位移。如果每次连发都像输入滞后，再测把全局顿帧留给高重要度事件。

在同一间矿房用同一把法器，比较空放、普通命中、击杀以及连发穿火。现版已经有符火、后坐、镜头、命中和击杀表现、分层声音。命中和击杀用 C-EVT 分开触发，玩家的火、毒烟等环境 DoT 已免于全局顿帧。D1 要求反应通过颜色、声音、文字中至少两路表达，并保持战场因果可读。[反馈规范](../../../docs/tech/m1-feedback-juice.md) · [环境 DoT 试玩修复](../../../docs/log/2026-11-21-05-playtest-physics-fluid-settle-fixes.md) · [当前反馈实现](../../../game/scripts/feedback/feedback_director.gd) · [项目路线 D1](../../../docs/01-decision-twist.md)

## 决策比较

| 玩家遇到的症状 | 优先查看 | 代价与复议条件 |
|---|---|---|
| 暂时无法复现，或现版能稳定辨认结果、火势和站位 | 保留现版并记录场景 | 无实现成本。M1-06 实战中复现后再开对应 A/B |
| 听到施法，仍分不清打空、打中、击杀 | [拉开结果声线](#outcome-feedback) | 单条临时音源或参数实验。纯听感改善需要实机重复出现 |
| 镜头干扰对敌人、角色和危害边缘的判断 | [减弱镜头位移](#camera-impulse) | 先测一处镜头位移倍率，可能牺牲力度。辨识稳定就保留有效的低档 |
| 连续命中时移动或模拟节奏显得断续 | [缩小全局顿帧的事件范围](#hitstop-scope) | 会削弱普通命中停顿。只有连续性明显改善且仍听得出、看得出命中才继续 |

### outcome-feedback

**拉开结果声线。** 用一次命中音色变化帮助玩家区分施法、普通命中和击杀，固定镜头、粒子和玩法参数。

- **证据与边界**　S1、S2 给出分层声音的教程线索，属于同一作者。S3 的预注册 Action RPG 实验发现，随成功程度变化的强化反馈提升了胜任感等动机指标。该实验中无差别放大反馈的一个条件降低了部分指标。对本作音色单独有效的判断仍是待证假设。
- **本作映射**　`_hit()` 和 `_kill()` 已各有音源，施法也有自己的声音。可复用 `sfx_bank.gd` 与 C-EVT，只替换或调制普通命中声以检查辨认差值。
- **代价与依赖**　程序低、音频低、内容无新增、系统影响低。依赖现有音源和能同时重现打空、命中、击杀的灰盒场景。
- **最小验证**　对照现版，B 只改普通命中音色。制作人在同样动作和目标条件下交替试 A/B，记录把空放听成命中或把普通命中听成击杀的次数，并检查火焰、反应声音是否仍可辨。误判可重复减少且反应声能听清才保留，否则还原。

### camera-impulse

**减弱镜头位移。** 通过同场景 A/B 判断较低的镜头位移能否在保留命中感的同时改善追踪。

- **证据与边界**　S4 的 GDC 讲稿把镜头反馈描述为事件累积的力度及随时间回落的振幅，属于开发者演示。S5 的官方指南明确建议允许关掉镜头震动，列出已发行的 Halo Infinite 强度设置。两者分别提供调节手段与运动舒适度边界，适合验证低强度选项。
- **本作映射**　`_shake()` 已有方向、振幅、时长和衰减。先用本地试验倍率降低现版命中镜头位移，固定目标粒子与声音。画面仍需要看得清反应，后续是否提供设置由实测再议。
- **代价与依赖**　程序低，美术、音频和内容无新增，可能削弱单次冲击。依赖窗口实机，镜头震动在当前 headless 路径中跳过。
- **最小验证**　同房间、同目标、同视距，A 用现版，B 只降低命中镜头位移。对比追踪敌人与火焰边缘有无中断，再复述动作结果。追踪稳定改善且命中仍清楚才保留，否则还原。

### hitstop-scope

**把全局顿帧留给高重要度事件。** 连发出现卡手时，将普通命中当作试验开关，保留击杀等较重事件的现行反馈，并保留现有的环境 DoT 豁免。

- **证据与边界**　S6 的《丸霸无双》制作人演讲实录描述用不同的时钟让命中特效与其他对象按不同节奏运行，提供已发行作品的实施案例。S7 的 Godot 4.5 文档说明全局 `time_scale` 影响使用 `delta` 的逻辑及计时器。缩小事件范围是针对本作连发与物质模拟的试验方向，仍需本地验证。
- **本作映射**　`_hit()` 和 `_kill()` 各自调用 `_hitstop()`，基于真实时钟复位。`_player_hurt()` 为指定环境 DoT 提前返回。留在反馈层做试验，复用现有 C-EVT，分别检查普通命中、击杀与玩家穿火。
- **代价与依赖**　程序低、美术/音频和内容无新增，普通命中会少一层力度。依赖现有反馈导演和 `--t4b-smoke` 的顿帧、复位及环境伤害断言。
- **最小验证**　A 用现版，B 仅取消普通命中的全局顿帧。跑单发、连续命中和穿火，检查移动是否持续、命中与击杀能否辨认；更新相应 smoke 预期并验收高重要度事件的顿帧和复位。体感未能重复改善或读不清命中时，恢复现版。

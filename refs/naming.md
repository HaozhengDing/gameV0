# 命名与世界观实验室 v0.1

> 解决两个卡点：**角色/地名/组织怎么起名**，以及**世界架构怎么搭**。
> 原则：拆结构，不抄专名；先能读、能记、能分组，再谈意境。

## 1. 十条命名规律（从收录作品里拆的）

1. **本名接地气 + 一个拔高的称号**：李火旺 / 丹阳子；杜丰于 / 无。普通人名负责真实，称号负责世界观。
2. **术语反用 / 错位**：坐忘道——本该是修行法门，被用成骗徒组织名。读者懂一点道家词，顿时毛骨悚然。
3. **神名 = 正神词 + 一个扭曲修饰**：慈孤观音（慈+孤+观音）、大黑佛母（大+黑+佛母）、何罗神。
4. **组织 = 理念/动词 + 道/教/坛/会/司/宗**：慈母教、慈孤坛、陆心青年会、中华异学会。
5. **地名 = 颜色/器物/方位 + 渡/驿/观/村/庄/寨/窟/洲**：白玉京、陈家庄、山阴、真仙观、九龙城寨。
6. **概念造词 = 单字根 + 对仗**：心素；境界名用现成道教词改造：红尘仙、阴司君王。
7. **体系 = 数字/阶位**：三十六洞天、序列 9→0、四大家族——数字让体系有「爬」的感觉。
8. **异象 = 反常识组合**：暖雪、黑太岁、雾海——把两个不该在一起的词硬拼。
9. **无名化 = 它 / 编号 / 代号**：动物园的「它」、SCP 编号——不给名字，恐惧更大。
10. **文本即命名**：游客指南、员工手册、水族馆通知——用机构说明书体命名，比任何怪物名都冷。

补充一条：**音译 + 本土化**。巴虺、何罗神是音译感；传武把克苏鲁、克图格亚、拉莱耶、深潜者直接翻译进中国修行体系——音译保留异质感，本土化保留可理解性。

## 2. 原创命名种子（先挑 3–5 个用，别全用）

**人名**：沈渡、柳三更、祝小满、裴不言、宋无咎、陆知白、虞照、祁雾
**道号**：玄枯子、丹烬子、守默子、青蚨散人、拾骸真人、无还子
**诨名**：纸马张、灯下客、三寸舌、拾骨婆、哑郎中
**组织**：拾骨道、无还坛、青灯会、归墟司、守夜宗、烬灯教
**地名**：白螺渡、赤沙驿、鸦青观、断念崖、九曲窟、阴米镇、纸坊村、雾隐洲
**神怪**：赤瞳娘娘、无面佛、黑潮公、空肚神、拾子母、阿阇罗（音译）
**异象**：倒悬雨、哑雪、红雾潮、无声雷、蚀月、纸灰风
**体系**：灯阶九品、泥丸 / 重楼 / 尸解（内丹术语作境界）、十二傩面、三不渡
**规则文本**：《夜巡须知》《纸马铺价目表》《渡口守则》《拾骨人契》
**命格名**（「请神/摸骨」用）：灯下骨、无面客、拾子命、哑口禅、纸人身、还债相

用法：**两层名字**——本名 + 称号/道号；组织/地名先定后缀（道/坛/会/司；渡/驿/观/窟），再往前填词。

## 3. 世界架构的 8 种零件

| 零件 | 作用 | 例子 |
|---|---|---|
| 双世界 | 现实/异界互为镜像，制造不可靠叙述 | 道诡异仙 |
| 境界体系 | 给玩家「爬」的目标 | 传武·红尘仙/阴司君王 |
| 私坛神系 | 正神借壳，交易型恐怖 | 还愿·慈孤观音 |
| 规则空间 | 规则即玩法、文本即关卡 | 动物园规则怪谈 |
| 异象地理 | 一个反常天象/地点重写世界 | 暖雪、雾海、地海 |
| 组织机关 | 收容/教派/官僚体系 | SCP-CN、慈母教 |
| 时间结构 | 轮回、渡劫、六年前后 | 双瞳、咒 |
| 宗族业障 | 家族的债传给下一代 | 黑太岁、还愿 |

**组合公式**（直接可用的三种）：
1. 双世界 + 私坛神系 + 规则文本 → 你白天在现实上班，晚上按「规矩」给另一个世界办事。
2. 异象地理 + 组织机关 + 时间循环 → 一个被「暖雪」封住的小镇，每七天重置，只有某个组织记得上一次。
3. 境界体系 + 宗族业障 → 修行境界越高，家族背的债越重，最后要拿血亲还。

**三个原创世界种子**（不抄任何现成作品）：
1. **香火账**：神靠香火记账，人死后债务转生；玩家是催债的阴差，要在阳间收账。
2. **纸活**：阳间烧什么，阴间就多什么；纸扎匠是唯一能「改设定」的人，也是唯一不能死的人。
3. **哑村**：全村禁忌是不能说出某个字，说了就会应验；玩家要找出那个字，又永远不能说出它。

## 4. 怎么用
- 先写 3 个名字 → 放进对应 faction/地名表 → 一周内做 30 秒原型验证「读起来有没有味」。
- 命名先定两层（本名 + 称号），再定组织/地名后缀；一次不要超过 3 个生僻字。
- 英文本地化：专名优先音译，概念词优先意译（如「心素」→ Heart-Seed 之类）。
- 避雷：生僻字堆砌、中二、直接挪用现有作品专名（会被一眼认出）。

## 5. 玩法界面与符箓命名克制原则（2026-11-20 用户拍板）
- **基础资源不造包装词**：血量、魔力、浮空等基础 HUD 状态优先用**彩色条/格子 + 数字**直接表达，不堆「灵力/盏/回符」等长文标签（类似 Noita）。
- **符组不另起合体名**：拼出来的法术句子按组成直接显示（如 `斩 + 爆`、`火 + 化水`），不编中二组合名。
- **符卡两分法**：
  - **明确有出处的正统道教符语保留**：如符头/法词 `急急如律令`、`天罡`、`敕·触`、`奉·时`、`五雷`、`镇`、`归`；
  - **其余动作/效果一律克制单字或 1–2 字直白功能词**：如 `斩`、`火`、`阴`、`掘`、`生`、`爆`、`吸`、`化水`、`分`，删去神兽/网文/中二修饰词（如「毕方火」「飞剑·煞」）。
- **物品与物质**：日常/民俗实词直称（`水`、`油`、`水银`、`煤`、`硫磺`、`糯米`、`葫芦`），不画蛇添足。

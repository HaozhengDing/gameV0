## D1｜核心 twist：可读的元素沙盒

### 是什么

- 玩家用**符头 / 符胆 / 符脚**拼出一句法术，打在会燃烧、流动、反应的民俗物质上；物质又反过来改变法术（葫芦装一壶水银喷出去、朱砂 + 纸现场画符）。
- **"可读"是硬约束**：每条反应用颜色 / 声音 / 文字中至少两种表达；同样的输入产生同样的结果；玩家已经学会的规则永远不被遮蔽（见 D3）。
- 深做的只有三样：`sim_core`、反应表、符箓 VM。其余系统一律做薄。

### 为什么

1. **设计底座本来就是沙盒。** 设计原文的每个大章都建立在可模拟物质上：地层按主题物质划分（2.3）；秘密层是物理谜题（往九缸灌液体解洛书、烧龟甲读裂纹、凿混沌七窍）；阴面靠物质映射生成；纸扎要"在模拟里烧干净"。以规矩为主，设计原文大半作废；以沙盒为主，brief 只需放弃"规矩系统"一项。
2. **全案最强的叙事核心只在沙盒里成立。** "符箓就是'它们'的文字"（设计原文 2.1，批注 C22 列为保留）：施法是核心动词时，玩家每一次念符都在使用敌人的语言——知识即代价、工具即污染源，这才是本作的克苏鲁。规矩怪谈的恐惧来自"不知道规则"，方向正好相反。
3. **data 层已按沙盒建好。** `data/materials.json`（12 物质 / 8 反应）、矿井 biome 的物质分布与 hazard、`data/rooms/` 的网格房间，都假定世界是可模拟的物质。
4. **第一层的教学只在沙盒里成立。** 旱魃（火 BOSS）逼玩家用葫芦装环境水再喷出去；没有可采集、可携带、可发射的液体，它就退化成一把"水属性武器"。
5. **两线并行，成本是乘法。** 每条"真规矩"都需要一个能被物理验证的因果；规矩数量 × 可验证因果，内容成本随两边一起放大。只做深一条，另一条借用它的因果。
6. **差异化（假设，待验证）。** 规则 / 认知恐怖已有 World of Horror、Cultist Simulator 等成熟作品；"国风 × 法术编程 × 物质沙盒"的组合尚未见到成熟作品。这是印象而非调研结论（批注 C03），对外宣传前补一次竞品检索。

### 代价

- brief 的"先网格化 CA"作废：目标是 Noita 式细粒度模拟，具体粒度由 M0 实验 A 实测决定（D4）。
- 项目最难的技术活（模拟并发、像素刚体、符箓 VM 语义）落在一个人 + AI 身上，而这几块恰恰是 AI 生成代码最难自证正确的部分（批注 C41 / C43 / C46）。对策见 D4。
- 放弃规矩怪谈作为独立玩法的深度（D2）。

## D2｜规矩 = 关卡的叙事规则层

### 是什么

采用批注 C18 的三层划分：**物质反应 / 符法交互 / 叙事规则**。规矩属于第三层：没有自己的状态机，也没有自己的数值。只有两种形态：

- **(a) 提示文本**：`biome.rules` 中真假混排的碑文 / 口述 / 八卦 / 游记残页，靠玩家交叉验证。
- **(b) 硬规矩**：违反的后果必须落成**世界里看得见的事件**——一次物质反应、一团物质涌出、一个实体出现。**不直接扣神智或其他数值。**
  - 现在就能落地：「矿里不能用明火」→ 明火进入硝 + 硫 + 煤混合区触发 `r-black-powder`，接触纯硫触发 `r-sulfur-toxic-smoke`。
  - 现在就能落地：「子时莫应声」（E-0001）→ 应声则身后涌出阴气（阴性伤害，熄灯）并引来追猎者；撒糯米可净化（`r-rice-purify`），朱砂贴符可现出脚印（`r-cinnabar-talisman`）。
  - 目标形态：水银池边念"归" → 汞蒸气扩散。前提是反应表补齐「汞蒸气」物质和「施法触发」类型（当前只有 `contact` / `heat`）；补齐之前，这条规矩维持 (a) 形态。
- 需要新增独立状态机的规矩（违规计数、跨区域规矩链等）一律不做。

### 为什么

- 规矩的后果复用沙盒的因果，不额外维护一套规则引擎。
- 玩家验证规矩的手段（符 + 物质）就是主玩法的动词——"用符验证规矩"本身就是一次组合实验（P0 评估问题 5）。
- brief 的体验支柱"恐惧来自规则不明但可推理"得以保留：反应表前后一致，所以规矩可推理。

### 代价

- 没有违规计数、追猎状态机、规矩链之类的设计空间。
- 规矩的表现力受限于反应表的覆盖面；反应表没有的因果，规矩只能停在提示文本层。
- W-0002（规则怪谈）的参考价值降到"规矩文本怎么写"这一层。

## D3｜神智 = 符箓的代价轴

### 是什么

- 三魂神智（S-0004）保留，但定位是 D1 的价格标签，**不是第二个 twist**。
- 神智只从设计原文 1.4 的四个来源流失：**目睹不可名状之物、读禁书、身处阴面、念禁符**。普通施法不扣（批注 C22）；违反规矩不扣（D2）。
- **污染只遮蔽未知，不遮蔽已知**（批注 C13）：可以腐坏未鉴定物品的描述、碑文、地图标记，可以生出幻觉敌人；已学会的符名、法器属性、反应提示永不乱码。
- **禁符**：任何时候都可以念；念出 −20 神智，**下一次施法**整次变成幻符（反噬）。禁符与幻符永不在同一次施法中出现（细则见 S-0004）。
- **入魔可逆**（参考饥荒的理智系统）：神智归零入魔，<33 时的幻觉敌人全部变实；击杀它们回少量神智、掉落只有入魔时才有的「魇烬」；阴物不再主动攻击你；神智回到 ≥ 20 出魔。每次入魔留一道魔痕（本局神智上限 −10，最多 −30），防止反复刷入魔（细则见 S-0004）。
- **引入顺序**：M0 不做神智；M1 基础战斗成立后再加（批注 C28）。

### 为什么

- "符箓是它们的文字"需要一个落在规则上的代价，否则只是背景故事。
- 把污染限制在"未知"上，才不会和 D1 的"可读"打架：本作的乐趣是读懂、调试符组合，剥夺已知信息等于拆自己的核心。
- 入魔做成可进出的状态而不是另一条路线：单向的入魔路线等于资料片级内容（批注 C14）；可逆状态只需复用 <33 的幻觉敌人，一个人做得完，而且给了低神智一个"冒险换收益"的决策，而不是单纯惩罚。
- 禁符的反噬落在"下一次"而不是"这一次"：代价可预测、可规划（批注 C11），也不会出现"禁符刚念出就被幻符顶掉、永远放不出来"的死结。

### 代价

- 失去"界面全面说谎"的极端表现；低神智的恐惧更多靠幻觉敌人、失真的地图与文本。
- 失去设计原文"入魔即另一条路线和结局"的分量；身体变异、阵营变化、入魔结局推到 M2 之后，届时在可逆状态上叠加。

## D4｜范围由 M0 实验决定，不按人头定

### 是什么

开发方式：**个人制作人 + AI 实现**（批注版的审阅前提）。不预设团队规模，先用三个 go/no-go 实验回答"这条路走不走得通"（批注 C50），时间盒 8 周，2027-01-10 评审。

| 实验 | 内容 | 通过标准（v0 目标，可修订） | 不通过时 |
|---|---|---|---|
| **A 模拟性能** | 单线程 `sim_core`：沙、水、油、火、水银 + 挖掘。不做刚体碎裂（C43），不做多线程（C41） | 目标机上固定种子跑 10,000 tick：最坏场景（整屏 480×270 = 129,600 格全是流动的沙 / 水 / 火）p95 ≤ 6 ms/tick；典型场景（矿井灰盒，载入 3×3 屏）p95 ≤ 2 ms/tick。目标机与测法见表下 | 加粗粒度（2×2 / 4×4 像素一格）重测；仍不行再上多线程 |
| **B 符语义** | 符箓 VM 的形式规格 + 可执行测试用例：抽牌游标、符脚归属、触发预算、法力不足、无效句（C09 / C46） | 30 条用例全过；触发递归有深度与动作数上限 | 砍掉触发类符头，只留修饰类 |
| **C 10 分钟手感** | 1 张矿井灰盒 + P0 的 4 组符 + 葫芦 | 5 名外部试玩者中 ≥ 3 人在 10 分钟内自发完成一次"用符改环境 → 环境改法术"，并能复述因果（C52） | 复议本决策（见"反方向备忘"） |

**实验 A 的目标机与测法**

- 目标机：4 核 CPU，单核性能约 Intel i5-8400 / Ryzen 5 2600 级（2018 年的主流中端），8 GB 内存，1080p 显示。比 Noita 的 Steam 最低配置（双核 i5、4 GB）高一档，覆盖面仍然很大。
- 分辨率：1 格 = 1 世界像素，内部分辨率 480×270，整数 4 倍放大到 1080p。
- 预算：60 Hz 一帧 16.7 ms，模拟最多占 6 ms，其余留给渲染、玩法逻辑与音频。
- 测法：只计 `sim_core` 的 tick 耗时，报 p50 / p95 / p99；开发机比目标机强时，结果不算数，必须在目标级机器上复测。

- **MVP（M1）**= 矿井 1 层 + 洞天 + 符箓三段式 + 七星灯 + 神智与可逆入魔（D3）。`data/biomes/level-01-coalmine.json` 就是它的骨架。
- **M2 之前不做**：阴面、纸扎、鬼市、祠堂怨灵、入魔的深层内容（变异 / 阵营 / 结局）、双货币、像素刚体碎裂（设计原文风险 3、批注 C53）。
- **周期**：M0 之后按实测给出 MVP 的时间区间，不预先承诺。

### 为什么

- 设计原文的 4–6 人配置与实际开发方式不符；按人头定范围，会定出一个做不完的项目。
- 三个实验正好对应沙盒路线的三个致命风险：**跑不动、语义乱、不好玩**。

### 代价

- 8 周内没有可展示的"游戏"，只有三份实验报告。
- 若实验 A 只能靠加粗粒度通过，"像素物理"的卖点打折，需要靠符箓与民俗物质补足辨识度。

## D5｜命格三选一推到 EA 后

### 是什么

命格（S-0004 中的命格规则、D-0001 ~ D-0003）不进 MVP；卡片保留为 EA 设计参考；`magic_numbers.design.fate_in_mvp: false`。

### 为什么

命格的收益和代价大量挂在神智、禁符、怨灵上，这些系统本身还没成形；现在做命格等于在流沙上盖房（D-0002 已因禁符门槛取消而失效）。

### 代价

- brief 红线"随机必须有选择（3 选 1）"在 MVP 里改由**洞天传法三选一**承担。
- 开局 build 差异暂时只来自法器与符。

## deviations

- brief §4"先网格化 CA，不做逐像素模拟" → 细粒度物质模拟，粒度由 M0 实验 A 决定（D1 / D4）。
- brief §6"MVP 3–6 个月"及其范围 → M0 三实验 + 实测后估期；MVP 范围见 D4。
- brief §6"MVP 含命格三选一" → 推到 EA 后（D5）。
- brief §4"规矩怪谈式引导"作为关键系统 → 叙事规则层（D2）。
- brief §4"认知污染影响 UI 文字、物品描述、地图（会说谎）" → 只遮蔽未知，不遮蔽已知（D3）。
- 设计原文 1.3"禁符要求神智 < 某阈值" → 随时可念 + 下一次施法反噬（D3 / S-0004）。
- 设计原文 1.4"失爽灵：符名变乱码、法器属性不可见" → 已学会的信息不被腐坏（D3）。
- 设计原文 1.4"失幽精即入魔，进入另一条路线和结局" → 可逆状态，参考饥荒理智系统；变异 / 阵营 / 结局推到 M2 后（D3）。
- 设计原文 4.9"4–6 人团队 / M0 含刚体碎裂" → 个人 + AI，M0 为三个实验且不含刚体碎裂（D4）。
- 本文件上一版"MVP 9–12 个月、至少 1 名模拟程序 + 1 名玩法程序"撤销：与个人制作人 + AI 的开发方式不符，且周期在 M0 实测前无依据；改为 D4。

# 2026-11-20-03 T4b 首次实机试玩反馈：角色移动物理 & 去中二/极简命名建议

- 日期：2026-11-20
- 作者：Antigravity（记录用户实机试玩反馈 + 方案对比）
- 类型：评审 + 建议
- 篇幅：详细
- 触发：用户实机试玩 T4b（`8d0ad32`）后反馈：「不赖，就是移动是飞的没有物理模拟；技能/物品起名太冗长，比如血量/魔力/『飞剑·煞 / 毕方火·化·水 / 鬼火·镇 / 土遁·归』甚至没必要起名，或者起得太中二了不好听。Noita 好像没有起很多名字。」

## 结论

1. **反馈一（移动无物理）**：当前 T4b 为四向自由飘移，缺乏落地与重力手感。建议在 **T4b 内做最小 Noita 式物理移动**（重力 + 2–3 格碎屑自动迈步 + `W/Space` 有限浮空条，落地快充；仅改 `game/scripts/player.gd` 与 `hud.gd`，不碰 `sim_core/`），避免纯跳跃导致掉进房间 01 水银池底（距门洞 80 格）爬不上来。
2. **反馈二（命名冗长/中二）**：经核对，**Noita 确实几乎不起中二专名**——基础资源直接画条/图标+数字（HP/法力/浮空/氧气），**组合后的法杖/法术不给组合起名**（直接显示槽位图标/单卡直白功能词如 `Spark Bolt / Bomb / Digging Bolt / Water`）。建议区分两层：**① HUD 与基础资源去文言包装**（直接进度条/格子+数字，或直白叫血/蓝）；**② 取消「符组」合体名**，单张符改短、直白、功能优先（如 1–2 字平实词），仅把国风/怪谈质感留给世界观层面的极少数对象（地名、碑文、怪异物质与禁符），对齐 `refs/naming.md`「避雷：生僻字堆砌、中二」。
3. **本轮仅落盘记录与方案对比**，未改代码、数据或 D1–D5；待用户拍板后再落地到 `game/` 与后续 C-TEXT / `data/talismans.json`。

## 决定与理由（方案对比，待用户拍板）

### 1. 角色移动物理（T4b 灰盒范围内）

| 方案 | 是什么 | 为什么 | 代价 |
|---|---|---|---|
| **A. Noita 式重力 + 有限浮空（推荐）** | 向下重力 + 地面贴合 + 2–3 格像素碎屑自动迈步 + `W/Space` 向上浮空（带短暂浮空条，落地快充）+ 液体略减速可上浮；全在 `game/scripts/player.gd` 实现 | 有明确重力与落地感，且能从 80 格深的水银池/矿坑底飞回走廊门洞，不卡死、不用改房间结构；不改 `sim_core/` | 需在 `player.gd` 写约 70 行碰撞/迈步/浮空逻辑，并小幅调参防止单格碎沙卡脚 |
| **B. 纯重力 + 常规跳跃（无浮空）** | 只有平台跳跃 | 更像传统横版动作 | 现有 `room-01` / `room-02` 门洞在 `y=260`、池底在 `y=355`（高差 80 格），跳不上来，必须重改房间或加梯子/爬墙系统 |
| **C. 维持自由飘移，物理留 M1** | 不改 `player.gd` | 省 1 次迭代 | 实验 C 外部试玩手感发飘，削弱「像素洞穴」沉浸感 |

### 2. 技能/资源命名与 HUD 极简化（对照 Noita）

**Noita 做法核对**：
- 基础状态：红条（HP）、黄条（浮空）、蓝条（氧气/法杖 Mana），HUD 主视野**几乎不出现多余术语文字**；
- 法杖/法术组合：**不给组合命名**，玩家只看到图标槽位或单术名；
- 单张法术与物质：绝大多数是极直白的功能/物质名（`Spark Bolt` / `Bomb` / `Digging Bolt` / `Water` / `Oil`），仅少量高阶/彩蛋法术带神秘词。

| 维度 | 现状（T4b） | 建议方向（待拍板） | 代价 / 注意点 |
|---|---|---|---|
| **基础资源（血/蓝/浮空）** | HUD 写死 `灵力 80/80 \| 盏 7/7` | **图形条/格优先，少字或无字**：血量用红条或 7 格灯图标（不写「盏」字）、魔力用蓝条、浮空用黄条；数字紧贴条旁，必要时直白叫「血 / 蓝」或图标 | 若 M1-05 仍保留「七星灯（阳伤扣血 vs 阴伤熄灯）」双轴机制，可用 7 盏灯的**图标格**表达而不靠文字噱头 |
| **符组（组合技能）** | 强行起合体名：`飞剑·煞` / `毕方火·化·水` / `鬼火·镇` / `土遁·归`，还带 `F-0001` | **取消组合名**；HUD 直接按「槽位 / 组成」显示，例如 `[1] 射 + 爆`、`[2] 火 + 化水`、`[3] 阴 + 定`、`[4] 挖 + 回蓝`（或图标+极简 1–2 字） | 需在正式采纳后同步 `data/talismans.json` / `refs/cards/p0/talismans.yaml` / C-TEXT 规范；T4b 可先在 HUD 侧试跑 |
| **单卡/物品名** | `飞剑 / 毕方火 / 鬼火 / 土遁 / 煞 / 镇 / 归` | **选项 1（纯直白功能词，最像 Noita）**：`弹 / 爆 / 火 / 化水 / 挖 / 定 / 回蓝 / 瓶`；<br>**选项 2（克制国风单字，去神兽/中二词）**：保留极少平实民俗词（`水银 / 硫磺 / 糯米 / 葫芦 / 符`），法术动作本身用朴素单字/功能词（`斩 / 爆 / 燃 / 化水 / 掘 / 镇 / 返`），删掉「毕方火」「飞剑·煞」「急急如律令」等长词 | 选项 1 可读性最高但国风气质更依赖美术、物质与规矩文本承载；选项 2 在可读与题材感间折中 |

# 2026-11-16-01 入魔效果后移 + VM 第 3 条拍板

- 日期：2026-11-16
- 作者：DeepSeek
- 类型：决策 + 建议
- 篇幅：详细
- 触发：用户拍板「第三条整句不念」；并问「入魔效果能不能待定？影响大吗？我感觉可以按阵容角色设计不同的？」

## 结论

1. **VM 第 3 条已定**：灵力不足保持「整句不念 + 本轮结束」，不采用 Noita 式逐符部分施法；30 条用例不变，VM 实现不动。
2. **入魔具体效果可以待定**：D3 只锁骨架（可逆、进 0 出 20、魔痕、四个流失源、污染只遮蔽未知、禁符反噬）；心魔化形/魇烬/阴物中立/失控/魄灯代付等**效果清单留到 M1 计划定**（时间盒：M1 第 1 周）。
3. **影响**：M0 零影响；M1 中等（M1-08 需要一套可玩的最小集，否则低神智循环没有收益目标、试玩验证不了「冒险换收益」）；**按角色做机制分化影响大**（内容乘法），不建议在 M1/M2 做。
4. **「按阵容角色不同」**：当前「角色」是玩家卡 C-0001 的 5 个 variants（方士/书生/土夫子/傩公/鲛人后裔），身份系统本身在 EA 后（D3 元进度只解锁身份皮肤、不加数值；D5 命格也推到 EA 后）。建议：**角色差异先做表现层**（入魔文本/视觉/称呼/心魔外观可不同，机制共用），机制分化等身份系统立项后再评估，且优先挂在「洞天传法三选一」的局内 build 上，而不是按 5 个角色变体做乘法。

## 影响评估（入魔效果待定）

| 阶段 / 方面 | 影响 | 说明 |
|---|---|---|
| M0（现在） | **无** | 神智/入魔不在 M0；VM 只把 sanity clamp 到 0，不做入魔状态机；C-SIM / C-VM / C-ACT 契约都不含入魔 |
| M1 | **中** | M1-08「神智与可逆入魔」必须有最小可玩集（可感知的收益 + 代价 + 出魔路径）；清单可以后定，但**不能到 M1 中段还没有**。建议 M1 计划第 1 周定 1 套通用最小集（可先用 S-0004 草案的 5 条） |
| M2+ / EA | **大** | 每套独立入魔机制 = 敌人变体 + AI + UI + 数值 + 文本；按 5 角色分化 ≈ ×5，与个人开发 + D3「神智是薄系统」直接冲突 |
| 契约 / 技术 | **无** | 不涉及 C-SIM / C-VM / C-ACT；只影响 M1 玩法与 C-EVT / C-TEXT 的表达 |

## 对「按阵容角色设计不同」的建议

| 层 | 现在做吗 | 内容 | 成本 |
|---|---|---|---|
| 机制（收益/代价/失控规则不同） | **不做**（推 EA 后，身份系统立项后复议） | 每个角色一套入魔规则 | 内容 ×N，平衡与测试成本高；与 D3 薄系统定位冲突 |
| 表现层（文本/视觉/称呼/心魔外观） | **可以做**（M1 后段或 M2） | 同一套机制，不同身份有不同「入魔叙事」 | 低，不动平衡与用例 |
| 局内 build 钩子（洞天传法） | 可评估（M1-07 之后） | 2–3 个传法变体带不同入魔表现/小差异 | 中等，比按角色便宜 |

复议条件：M1 试玩后多数玩家觉得入魔「没有角色感」。

## 决定与理由

| 决定 | 为什么 | 代价 |
|---|---|---|
| 入魔效果清单待定到 M1 计划 | D3 锁的是「可逆框架」，效果清单是内容细节；M0 不依赖它；现在定死反而会在战斗/敌人未成形时押错细节 | M1 计划期必须把这活排进去（已写时间盒：第 1 周），不能无限拖 |
| 不做角色机制分化 | 个人开发 + AI 的内容乘法；D3 明确神智是薄系统不是第二 twist；身份系统本身在 EA 后（D5 同源） | 短期角色辨识度靠表现层补；若表现层不够，M1 试玩后再复议 |
| 表现层分化先做 | 低成本、保留角色感、不影响平衡与测试 | 只是「看起来不同」，玩法上仍是同一套入魔 |
| 第 3 条维持整句不念 | 用户拍板；句原子让「这发放不放得出」可预判，也保住 30 条用例与 T3 实现 | 差 1 点灵力整发哑火，手感比 Noita 硬（已知代价） |

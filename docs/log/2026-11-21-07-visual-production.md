## 1. 结论

**推荐"引擎原生程序化 + 只复刻运动参数"的最小切片，其余留 M2。** 不做整屏审美复刻。

三条理由：

1. **参考项目是装饰性交互艺术，没有玩法因果**。原版 Pixel Play（S2）是"点树会摇、拖树枝松手弹回、可以起风/起暴风"的网页作品；本作的画面必须服务 D1"看得懂物质在反应"。照搬会得到"好看但与玩法无关"的一层皮。
2. **它的运动层次正好补上本作缺的一层**：统一风场 + 每物体相位差 + 振幅随机 + 松手回弹 = "空气在流动"。矿井里恰好有瓦斯、硫烟、水银蒸气这些语义相近的物质。
3. **复刻工作流本身不稳定**：论坛经验（S4）"复刻着色器抽卡成功率五成算高了"，且"动图它其实看不太懂，最好再配几张关键帧加文字描述"。把不确定性放在"参数"可控，放在"整套视觉"不可控。

## 3. 最小验证（一周内）

- **场景**：固定 seed `20261121` 的入口安全区 +向北 3 屏矿道；基线 = 当前 build。
- **只改一个变量**：新增环境层（风场 1 张 2D 噪声 / 每屏 ≤40 粒子、寿命 0.8 s / 灯火呼吸 ±4%、周期 3.2 s）。
- **观察**：1080p GL Compatibility 帧时间增量 ≤ 0.5 ms；10 s 录屏 A/B 盲选 ≥2/3；8 条反应的辨识度按 M1-10 核对表不打折。
- **回退**：`ambience_enabled = false` 一条开关关掉整层。

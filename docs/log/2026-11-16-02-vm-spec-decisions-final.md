## 决定与理由

| 决定 | 为什么 | 代价 |
|---|---|---|
| #1 单位取句 | 三段式语法里一句=一次施法块，与 Noita 的 cast block 对应；改符数会重定义符头/符胆/符脚归属 | 手感与 Noita 的「Spells/Cast 按符」不同，玩家需要学「句」概念（M1 教学承担） |
| #4 归 cost 0 / 返还 8 | F-0004 卡面（spirit_cost 10, refund 8, net 2）只有这个读法自洽；与 Noita 的 Add Mana 负蓝耗语言一致 | S-0002 的 foot_cost +8~+30 出现唯一例外，需长期维护 deviations |
| #5 上限 3/64/32 | 深度 3 给符头组合留空间（比 Noita 递归上限 2 松一档）；64/32 保确定性与性能 | 极端 build 会被钳制，需要 UI 可读提示（M1 做） |
| #6 替换取 Option B | 不改 C-ACT、确定性强、成本不变；30 条用例已按此实现 | 替换会吞掉该句触发（敕·触 + 幻符 组合失效），备选 A 留档 |
| T1 状态改「冻结候选」 | 6 条决策项已清，T3 已按 30/30 回归，可作为 T4a/T4b 稳定输入 | §7.4 仍有数据缺口/待定边界（化金、墨、蒸汽、幻符池、洗牌 RNG），T4b 前需补；改语义仍需先改用例 |

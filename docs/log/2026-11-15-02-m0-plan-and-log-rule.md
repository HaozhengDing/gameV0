## 决定与理由

| 决定 | 为什么 | 代价 |
|---|---|---|
| 先做 T0 数据校验 | 本日发现的不一致全靠人工 grep；多个 agent 并行改数据后，必须让机器检查 | 每加一种数据都要补校验规则 |
| T1 规格先于 T3 实现 | 批注 C09：VM 语义是最需要先冻结的协议；先写用例，AI 实现才有对错标准 | 前两周没有"会动的东西" |
| `sim_core` 用 C++17 + CMake | Godot 官方 GDExtension 绑定是 C++，接入路径最短 | 内存安全靠纪律与 sanitizer；用户更熟 Rust 的话，只能在 T2 开工前改 |
| 规则写进 AGENTS.md | AGENTS.md 是多数 coding agent 默认读取的约定文件；CLAUDE.md 只做指针，避免两份规则不同步 | 不读这两个文件的工具，需要人工把 AGENTS.md 贴进系统提示 |
| 摘要 / 详细按客观条件区分 | "视情况而定"需要可执行的判断标准，否则每个 agent 标准不一 | 条件可能偏严，导致详细篇偏多 |

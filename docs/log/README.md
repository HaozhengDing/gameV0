## 模板

篇幅判断：

- **摘要**（≤ 30 行）：单一小改动、不涉及新决策、不改数值。只写"元信息 / 结论 / 改动 / 下一步"。
- **详细**：满足任一条即用——新决策或推翻旧决策；改动 ≥ 3 个文件；改了数值或公式；给出任务计划或方案对比；新增或修改了 deviations。

```markdown
# YYYY-MM-DD-NN 标题

- 日期：YYYY-MM-DD
- 作者：人名 / agent 名（如 Claude、DeepSeek）
- 类型：建议 / 更新 / 决策 / 评审
- 篇幅：摘要 / 详细
- 触发：谁提出了什么请求（一句话）

## 结论
一到三句话。

## 改动
| 文件 | 改了什么 |
|---|---|

## 决定与理由（详细篇必填）
每条写清 是什么 / 为什么 / 代价。

## 新增或修改的 deviations（详细篇必填，没有就写"无"）

## 未解决 / 待决定

## 下一步
```

## 6. 关键命令

```text
# 数据/用例校验（每次提交前）
python3 tools/validate_data.py

# sim_core + VM：构建与测试（7 个 ctest）
cd sim_core && cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release && cmake --build build
cd build && ctest --output-on-failure

# T4b 灰盒（需要 Godot 4.5 + godot-cpp 4.5；构建见 game/README.md）
godot --headless --path game -- --t4b-smoke          # 期望 T4B_SMOKE_OK 且 exit 0
godot --headless --path game --quit-after 300       # 期望 T4B_WORLD_READY，无 SCRIPT ERROR
godot --path game -- --t4b-shot                     # 窗口模式截图，存仓库根 t4b_shot.png
```

## 7. 已知限制与坑（别重复踩）

- **灰盒火**：只有油会自燃；煤/硫/竹木的 `flammable/ignition_temperature` 引擎还没消费（M1-12 反应表）；火格按墙处理、7 盏掉血占位、施法命中简化为即时命中。
- **C-SIM v2**：只在末尾追加过 9 种 data 物质；已有 id/语义/5 物质基准不变；破坏性改动必须版本号 +1 并写 log。
- MSVC 编译需 `/utf-8`（源码含中文）；Godot 4.4+ GDExtension 入口签名用 `GDExtensionInterfaceGetProcAddress`；cmd 批处理要纯 ASCII + CRLF；C++→GDScript 字符串必须 `String::utf8`（否则中文乱码）。
- `data/rooms` 的 grid 字符 = `tile_size`（16）×16 cells；不是 1 cell/字符。
- 实验 A 的基准是**开发机数据**，不是 go/no-go；目标机复测命令在 `docs/tech/m0-a-report.md` §7。
- T4b 的四组符/葫芦/关卡都是灰盒，不是正式设计；正式反应表、战斗、神智、七星灯都在 M1。

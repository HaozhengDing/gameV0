## 3. 预演暴露的 T5 试玩隐患（供开测前决定）

| 优先级 | 隐患 | 对实验 C 的影响 | 建议处理（待用户拍板） |
|---|---|---|---|
| **高** | **房间 01 左下有 1,536 格原生水** | 外部玩家看到蓝水会直接按 `E` 吸取灭火，根本不会尝试把水银「化水」，导致无法验证「用符改环境 → 环境改法术/道具」 | 选项 A（推荐）：仅在 T4b `level.gd` 灰盒放置时把房间 01 原生水改为水银或空（不动 `data/rooms/`）；<br>选项 B：保留原生水，但在试玩观察表里把「用原生水灭火」单独计分，不视作通过 D4 |
| **中** | **下方连炸 2 发 `[1] 斩 + 爆` 可挖穿火障下方岩层** | 玩家若一开始就用爆炸挖地道绕过火障，属于「用符改地形」，但未触发「环境改法术/葫芦」的第二段因果 | 建议保留沙盒自由度，试玩时记录绕路行为并在事后提问验证玩家是否理解因果 |
| **中** | **房间 02 硫磺/煤不爆炸、且表层点火易飞离熄灭** | 玩家读到 HUD「硫磺 · 可燃」后点火没炸出黑火药，可能误判规则失效 | 试玩后口头归类为已知 M1-12 范围；不为此在 M0 扩建反应表 |
| **低** | **煤粉（密度 1.4）浮在水银（密度 13.6）表面** | 若玩家潜入水银池正下方被浮煤挡头（3 格粉末），垂直上浮需横向错开几格 | 轻度地形特征，非死锁；观察外部试玩者是否会在此卡住 |

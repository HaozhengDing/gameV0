## 1. 结论

- 两条视频讲的是同一件事的两面：**射击爽感**是「枪口 → 后坐 → 镜头 → 命中 → 击杀 → 音效」的六层串联；**通用打击感**是「命中停顿 → 镜头震动 → 闪白 → 受击反应 → 粒子 → 音效」。交集是**音效 / 粒子 / 顿帧 / 镜头**，差异在「枪口」与「击杀」这两层。
- 本作并成 **8 层**：视频的 12 条并成 6 条，再加本作专属的 **反应环**（C-EVT `reaction_triggered`，直接服务 D1「看得见因果」）与 **熄灯 / 反噬**（D3「阴性伤害直接熄灯」「禁符反噬」必须最疼）。
- 全部挂在 **C-EVT** 上：**不改玩法数值、不加玩法状态**，只把既有事件翻译成表现。`sim_core` / VM / 战斗层零改动。
- 一条硬约束（D1）：**不做全屏强闪**。视频里"屏幕闪白"是最直接的命中信号，但本作可读优先——全屏白闪会短暂遮蔽已知信息。改为「目标处闪白 + 屏幕边缘红晕 + 极短低强度全屏补光（≤ 0.28 α / ≤ 0.09 s）」，见 §4 偏离 1。

## 2. 两条建议的原始拆解

| 层 | 射击爽感（视频 1） | 通用打击感（视频 2） | 本作合并后 |
|---|---|---|---|
| 1 枪口 | 枪口火光 + 光晕向外扩散 + 人物与墙短暂受光 | — | **符火**：光锥 + 径向光晕 + 人物/墙面受光 |
| 2 后坐 | 枪身先后退，角色被推一下 | — | **法器后坐**：人物视觉位移 + 弹簧回弹 |
| 3 镜头 | 沿开火反方向移动一下，后坐越大位移越大 | 镜头震动，再迅速恢复补稳 | **定向震屏**：反向脉冲 + 抖动，按威力缩放 |
| 4 命中 | 闪白 + 靶子晃动 + 顿帧 + 少量粒子 | 命中停顿 / 镜头震动 / 闪白 / 受击变形 | **命中**：顿帧 30 ms + 目标白闪 + 反向火星 + 伤害数字 |
| 5 击杀 | 顿更久 + 大量粒子 + 击退升级为击飞 + 更清脆的击杀音 | 命中粒子表现方向与力量 | **击杀**：顿帧 60 ms + 爆散 + 大光环 + 低音闷响 |
| 6 音效 | 开火 / 弹壳 / 命中 / 击发 分层 | 挥动风声 + 命中重击声 | **分层音效**：开火 / 符纸 / 命中 / 击杀 四层 + 阴伤 / 反噬两条专属 |

|---|---|---|---|

| 5 击杀 | `entity_killed`（target ≠ player） | `_kill()` → `fx_layer.impact(big=true)` | 顿帧 60 ms / 环 r 118 px / 光晕 r 90 px / 34 粒火星 |

## 4. 三条偏离与理由

### 偏离 1：全屏闪白 → 目标闪白 + 边缘红晕

- **是什么**：视频第 3/4 层的"屏幕闪白"降级为「目标处小范围白闪（0.05–0.09 s）+ 屏幕四边红晕（受击）+ 极短低强度全屏补光（≤ 0.28 α）」。
- **为什么**：D1 把"可读"写成硬约束；全屏白闪会在一瞬间遮蔽地形、火势与敌人位置，等于拿核心卖点换冲击力。视频面向的是"枪线爽感"主导的射击游戏，本作卖点是"看得懂物质在发生什么"。
- **代价**：单帧"炸裂感"弱于视频参考；需靠火花方向、伤害数字、震屏与音效补足。复议条件 = 制作人自测觉得击杀"不够爽"时，把击杀允许的 α 上限从 0.28 提到 0.40，但时长不超过 0.12 s。

### 偏离 2：顿帧用全局 `Engine.time_scale`

- **是什么**：命中 / 击杀 / 受击 / 反噬时把 `Engine.time_scale` 压到 0.06，30–60 ms 后复位（用真实时钟复位，不受缩放影响）。
- **为什么**：一次性冻结整个世界（含 `sim_core` tick）才有"卡住一下"的顿感；只在表现层做插值会变成"画面停了、火还在烧"。
- **代价**：`Engine.time_scale` 是全局的——将来做多人或录像回放会破坏同步，暂停菜单也要避开。M1 单机单线程，代价暂时为零。**风险**：复位逻辑异常会永久慢放，因此 `reset()` / `shutdown()` / `_exit_tree()` 三处强制回 1.0，并写进 smoke 断言。

### 偏离 3：音效运行时合成，不用采样

- **是什么**：`sfx_bank.gd` 用白噪声 + 正弦扫频 + 指数包络现场合成 16 bit PCM（22.05 kHz）：`fire` / `casing` / `hit` / `kill` / `lantern` / `backlash` / `fizzle`。
- **为什么**：M1 是灰盒，美术资源尚未进排期；合成的意义是**先把"分层"验证掉**——视频第 6 层的真正内容是"四层声音各司其职"，不是音色好听。
- **代价**：音色单薄、无空间感。复议条件 = M2 美术阶段按同一组事件键替换为采样，调用方不改。

## 6. 明确不做（留 M2 之后）

- 全屏强闪、动态模糊、径向模糊、镜头拉近 / 击杀特写、慢动作定格。
- 命中数字的暴击分色与连击计数（等 `weak_to` 倍率接入事件后再做）。
- 打击感的材质分化（打在矿鬼 / 纸扎 / 铁甲上不同音色）——M1 只有一条命中音 + 音高随机。
